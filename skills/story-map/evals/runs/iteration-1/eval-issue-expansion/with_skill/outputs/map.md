# Let users tag and filter saved articles (source: issue #4)

Legend: 🦴 = walking-skeleton slice

| Tag an article | Find articles by tag | Maintain tags |
|---|---|---|
| **Add a tag**<br>- 🦴 Add a freeform tag to a saved article<br>- Add several tags at once<br>- Suggest existing tags while typing<br>- Ignore a duplicate tag on the same article | **Filter the saved list**<br>- 🦴 Filter saved list by a single tag<br>- Filter by multiple tags<br>- Filter by tag by tapping a tag on an article | **Tidy up tags**<br>- Rename a tag across all articles<br>- Delete a tag from all articles<br>- Merge two tags |
| **Remove a tag**<br>- 🦴 Remove a tag from a saved article | **Leave the filter**<br>- 🦴 Clear the tag filter to see all articles | |
| **Tag on both platforms**<br>- Tag an article on mobile<br>- Tag an article on desktop<br>- 🦴 Tags sync between mobile and desktop | **Browse available tags**<br>- See a list of all my tags with counts | |
