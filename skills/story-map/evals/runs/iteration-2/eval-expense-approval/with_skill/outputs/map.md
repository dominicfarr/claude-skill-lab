# Expense reimbursement tool: submit, approve, pay

Assumptions: each employee has one manager recorded in the system; receipts optional in v1; single currency; sign-in already exists. 🦴 = walking skeleton.

## Journey 1: Submit an expense request

**Create the request**
- Submit a request with amount, date and description 🦴
- Attach a receipt image
- Save a draft and submit later

**Follow up on the request**
- See my requests and their status
- Withdraw a pending request
- Edit and resubmit a rejected request

## Journey 2: Review requests as a manager

**Find requests awaiting my decision**
- List pending requests from my direct reports 🦴
- Get an email when a request needs my decision

**Decide on a request**
- Approve a request 🦴
- Reject a request with a reason 🦴
- Ask the submitter for more information
- Delegate approval while I am away

## Journey 3: Pay out approved requests as finance

**Find approved requests to pay**
- List approved requests awaiting payment 🦴
- Filter payouts by employee or date

**Pay the request**
- Mark an approved request as paid 🦴
- Pay several requests as a batch
- Export a payment file for the bank
