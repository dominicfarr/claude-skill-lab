# Story Map: Let users tag and filter saved articles

Readers of a read-it-later app (mobile and desktop) can tag saved articles with freeform labels and filter their saved list by tag. Source: issue #4. (🦴 = walking skeleton)

## Journey 1: Tag articles

**Add tags to an article**
- 🦴 Tag an article on mobile
- 🦴 Tag an article on desktop
- Add several tags at once
- Suggest existing tags while typing
- Ignore a duplicate tag on the same article

**Remove tags from an article**
- Remove a tag from a saved article

## Journey 2: Keep tags consistent across devices

**Sync tags**
- 🦴 Tags sync between mobile and desktop

## Journey 3: Find articles by tag

**Choose a tag to filter by**
- 🦴 See a list of all my tags with counts
- Filter by tag by tapping a tag on an article

**Apply a filter**
- 🦴 Filter saved list by a single tag
- Filter by multiple tags

**Clear a filter**
- 🦴 Clear the tag filter to see all articles

## Journey 4: Manage tags

**Tidy up my tags**
- Rename a tag across all articles
- Delete a tag from all articles
- Merge two tags
